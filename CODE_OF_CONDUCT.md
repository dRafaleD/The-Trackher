# Code of Conduct

## Our Standard

We want Trackher to be a respectful, safe, and constructive open-source project.

Examples of positive behavior:

- being respectful in disagreements
- giving actionable technical feedback
- assuming good intent while staying honest
- prioritizing user safety and responsible use

Examples of unacceptable behavior:

- harassment, hate speech, or personal attacks
- publishing private data without consent
- encouraging abusive or unauthorized use of the tool
- deliberately misleading contributors or users about safety guarantees

## Enforcement

Project maintainers may remove, edit, or reject comments, issues, pull requests,
or other contributions that violate this code of conduct.

## Reporting

If you experience or witness unacceptable behavior, use the repository's
private contact or security reporting path where available.
